# AI Invoice Manager

AI Invoice Manager is a full-stack web application designed to help businesses
create, manage, and track invoices digitally.

The project combines traditional invoice management features with AI-assisted
functionality to reduce manual work involved in creating, searching, and
managing invoices.

## 🚀 Project Status

The project is currently under development.

### Completed

- Node.js and Express backend setup
- PostgreSQL database integration
- User registration API
- User login API
- Password hashing using bcrypt
- Customer database structure
- Invoice database structure
- Invoice items database structure

### Upcoming

- JWT authentication
- Customer CRUD operations
- Invoice CRUD operations
- React frontend
- Dashboard
- Invoice generation
- AI-powered invoice assistance using Google Gemini
- AI-based invoice search and processing
- Testing and deployment
